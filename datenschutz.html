Wer die Anwendung nutzt

Projekt-Master ist ein privates Werkzeug mit genau einem Nutzer, dem Betreiber selbst. Die Anwendung ist nur über ein privates Netzwerk erreichbar und nicht öffentlich zugänglich.

Zugriff auf Google-Daten

Die Anwendung fordert ausschließlich die Berechtigung calendar.app.created an. Damit darf sie nur Kalender anlegen und verwalten, die sie selbst erstellt hat. Sie legt den Kalender „Projekt-Master“ an und schreibt dort Termine zu Vertragsfristen. Andere Kalender, Termine, E-Mails oder Kontakte werden nicht gelesen.

Speicherung

Das Zugriffstoken von Google wird verschlüsselt übertragen und nur auf dem eigenen Server des Betreibers gespeichert. Es werden keine Daten an Dritte weitergegeben, verkauft oder für Werbung genutzt. Die Berechtigung lässt sich jederzeit unter myaccount.google.com/permissions widerrufen.

Google API Services User Data Policy

Die Nutzung und Weitergabe von Informationen, die Projekt-Master über Google-APIs erhält, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).
